# Task Manager API

A simple REST API for task management, built with **Node.js, Express and TypeScript**.

This project is part of my backend development learning journey, focusing on REST API development, TypeScript, code organization and software architecture.

## 🚀 Technologies

- Node.js
- Express
- TypeScript
- REST API


## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/task-manager-api.git
```

Navigate to the project directory:

```bash
cd task-manager-api
```

Install dependencies:

```bash
npm install
```

### Running the project

Start the development server:

```bash
npm run dev
```

The API will be available at:

```text
http://localhost:3000
```
